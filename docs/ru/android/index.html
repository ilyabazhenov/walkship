Установка

  1. Нажми Скачать APK и открой файл, когда он скачается.
  2. Android попросит разрешить установку приложений из браузера — разреши один раз.
  3. Открой Walkship и отсканируй QR-код с экрана настройки в приложении на Mac.

Обновления

Приложения, установленные так, Android сам не обновляет. Добавь Walkship в Obtainium — оно будет ставить новые версии из релизов на GitHub, как только они выходят.
