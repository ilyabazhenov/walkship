Walkship for Android

Android 7+ · the phone app for Walkship on your Mac

Download APK

Install

  1. Tap Download APK and open the file when it has downloaded.
  2. Android asks to allow installing apps from your browser: allow it once.
  3. Open Walkship and scan the QR code from the Mac app’s setup screen.

Updates

Android doesn’t update apps installed this way on its own. Add Walkship to Obtainium, and it will install new versions from GitHub releases as they come out.
