# Security · Безопасность

Found a vulnerability in Walkship — the Mac app, the phone app, the relay or this website? Please report it
privately: **[Report a vulnerability](https://github.com/ilyabazhenov/walkship/security/advisories/new)**
(the Security tab of this repository). Don't open a public issue for it.

Нашли уязвимость в Walkship — в приложении на Mac, на телефоне, в ретрансляторе или на этом сайте? Сообщите
приватно: **[Report a vulnerability](https://github.com/ilyabazhenov/walkship/security/advisories/new)**
(вкладка Security этого репозитория). Пожалуйста, не открывайте для этого публичный issue.

Fixes ship in the latest version only; the Mac app offers updates from the menu bar. ·
Исправления выходят только в последней версии; приложение на Mac предлагает обновление из строки меню.

How Walkship handles your data: [privacy policy](https://walkship.app/privacy/) ·
Как Walkship обращается с данными: [политика конфиденциальности](https://walkship.app/ru/privacy/).
