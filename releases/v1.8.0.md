## Update both apps together · Обновите оба приложения вместе

Walkship 1.8.0 on the Mac talks only to Walkship 1.8.0 on the phone, and the other way round: an older phone app
asks to be updated, a newer one asks to update the Mac. Update the Mac and the phone at the same time. ·
Walkship 1.8.0 на Mac работает только с Walkship 1.8.0 на телефоне, и наоборот: старое приложение на телефоне
попросит обновиться, новое — обновить Mac. Обновите Mac и телефон одновременно.

## New · Новое

- **Encrypted connection.** Everything between the phone and the Mac is encrypted — what you say, the replies,
  the voice, pictures and mockups — at home, in a café, anywhere. The access token never goes over the network:
  the apps prove they know it without sending it. Plain requests over the network are refused; only the Mac
  itself talks to its server in the clear. · **Зашифрованная связь.** Всё, что идёт между телефоном и Mac, —
  реплики, ответы, голос, картинки и макеты — зашифровано: дома, в кафе, где угодно. Токен доступа по сети не
  передаётся: приложения доказывают, что знают его, не пересылая. Незашифрованные запросы по сети сервер не
  принимает; открытым текстом с сервером говорит только сам Mac.
- **The assistant reads only the project.** In a conversation the assistant reads the files of its project and
  nothing else on the Mac; files with secrets (.env, keys, certificates) stay closed even inside the project. ·
  **Ассистент читает только проект.** В разговоре ассистент читает файлы своего проекта и больше ничего на Mac;
  файлы с секретами (.env, ключи, сертификаты) закрыты даже внутри проекта.
- **Agents in a sandbox.** An agent that implements a feature writes only in its own copy of the repository,
  can't read your keys and logins, and has no network: dependencies come from the project's main folder. The
  repository's hooks and git settings are out of its reach, and a run that tried to change them isn't
  accepted. · **Агенты в песочнице.** Агент, реализующий фичу, пишет только в свою копию репозитория, не видит
  ваших ключей и входов и работает без сети: зависимости берутся из основной папки проекта. Хуки и настройки git
  ему недоступны, а прогон, который пытался их изменить, не принимается.
- **A pull request only after your «yes».** The assistant asks first and shows where the branch goes; answer
  «yes» by voice or tap the button. · **Пул-реквест — только после вашего «да».** Ассистент сначала спрашивает и
  показывает, куда уйдёт ветка; ответьте «да» голосом или нажмите кнопку.
- **Connected services with care.** A config pasted from a README is shown first — what it runs and what it
  connects to — and connects only when you tap. Tools that may change data start switched off. · **Сервисы —
  аккуратнее.** Конфиг из README сначала показывается — что он запустит и куда подключится — и подключается
  только по кнопке. Инструменты, которые могут менять данные, сначала выключены.
- **The phone asks before switching to another Mac** when it opens a connection link. · **Телефон спрашивает,
  прежде чем переключиться на другой Mac** по ссылке подключения.
- The voice pack installs exactly the pinned packages and models, checked by their hashes. · Голосовой пакет
  ставит ровно закреплённые версии пакетов и моделей с проверкой контрольных сумм.
