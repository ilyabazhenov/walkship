## Fixed · Исправлено

- **Add project now lists every folder in the projects folder.** Before, a folder showed up only with git,
  a README or a package file, so a plain folder with documents could not be added. Folders without git
  are marked: you can talk about them, but coding agents can't run there. · **При добавлении проекта теперь
  видны все папки из папки проектов.** Раньше папка появлялась, только если в ней был git, README или файл
  сборки, и обычную папку с документами нельзя было добавить. Папки без git помечены: обсуждать их можно,
  а запускать в них реализацию — нет.

Everything from 1.11.1 — server settings in a wide window, choosing the projects folder in the system
dialog — is here too. · Всё из 1.11.1 — настройки сервера в широком окне, выбор папки проектов в
системном диалоге — здесь тоже.
