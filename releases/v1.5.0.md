**Go for a walk. Come back to a PR.** · **Ушёл гулять — вернулся к готовому PR.**

The first public release of Walkship — a voice partner for your projects: talk a feature through on a walk,
Walkship writes the spec, and Claude Code builds it on your Mac. · Первый публичный релиз Walkship — голосового
партнёра для твоих проектов: обсуждаешь фичу на прогулке, Walkship собирает спецификацию, а Claude Code реализует её
на твоём Mac.

> The interface and the voice are Russian-only for now. · Интерфейс и голос пока только на русском.

## What's in it · Что умеет

- **Hands-free voice discussions** that know your code, git history and past talks. · **Голосовые обсуждения
  hands-free**: ассистент знает код, историю git и прошлые разговоры.
- **Summaries into features** with a spec and acceptance criteria. · **Итоги в фичи** со спецификацией и критериями
  готовности.
- **Implementation by Claude Code or Codex** in a separate git worktree, a push when done, a PR on your word. ·
  **Реализация агентом Claude Code или Codex** в отдельном worktree, пуш по готовности, PR по твоей команде.
- **Feature board, quick notes, memory, a spoken digest, mockups.** · **Доска фич, быстрые заметки, память, сводка
  голосом, макеты.**
- **MCP**: Walkship as an MCP server for Claude Code, Cursor and Codex, and your own MCP servers for the assistant. ·
  **MCP**: Walkship как MCP-сервер для твоих агентов и внешние MCP-серверы для ассистента.
- **Everything local**: no Walkship cloud, no accounts, no API key. · **Всё локально**: без облака, аккаунтов и
  ключа API.

**Coming from Dictum? · Переходишь с Dictum?** The Mac app has a new identity, so macOS asks for the microphone and
login-item permissions again. Your data in `~/.voice-assistant` is kept. Delete the old Dictum.app by hand. ·
У приложения на Mac новый идентификатор: macOS заново спросит доступ к микрофону и автозапуск. Данные в
`~/.voice-assistant` сохранятся. Старый Dictum.app удали вручную.
