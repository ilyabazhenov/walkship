**Server settings are back on the Mac, with a folder picker for projects.** · **Настройки сервера снова на Mac, а папку проектов можно выбрать в диалоге.**

## Downloads · Файлы

| | |
|---|---|
| `Walkship-1.11.1-arm64.dmg` | Mac with Apple Silicon, macOS 14+. Signed and notarized. · Mac с Apple Silicon, macOS 14+. Подписан и нотаризован |
| `latest.json` | Used by the apps to check for updates. · Для проверки обновлений в приложениях |

The Android app stays at 1.11.0. · Приложение для Android остаётся на 1.11.0.

## Fixed · Исправлено

- **Server settings open again in a wide window.** Server → Server settings, next to Restart and Stop.
  · **Настройки сервера снова открываются в широком окне.** «Сервер» → «Настройки сервера», рядом с
  «Перезапустить» и «Остановить».

## Changed · Изменено

- **Choose the projects folder in the system dialog** instead of typing the path. · **Папку проектов можно
  выбрать в системном диалоге**, а не вписывать путь руками.
- When no folders are found, the hint says where the projects folder is set. · Если папок не нашлось,
  подсказка говорит, где задаётся папка проектов.

The protocol is unchanged, so the phone and the Mac can be updated in any order. · Протокол не изменился,
поэтому телефон и Mac можно обновлять в любом порядке.
