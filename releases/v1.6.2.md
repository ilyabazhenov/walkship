## New · Новое

- **Conversations keep their prompt cache through pauses.** A discussion stays open for 55 minutes of silence instead
  of 10, inside the CLI's one-hour cache, so coming back to it doesn't send the whole conversation again. Your own
  Claude Code auto memory no longer leaks into conversations. · **Разговор не теряет кэш на паузах.** Обсуждение
  живёт 55 минут тишины вместо 10 — внутри часового кэша CLI, так что возвращение к нему не отправляет весь разговор
  заново. Твоя автопамять Claude Code больше не попадает в разговоры.
- **The request log names the CLI, the model and the tokens.** Each request shows which CLI and model answered it
  («Codex · gpt-5.6-luna · Conversation») and what each turn spent: cache read, cache written, fresh input, output.
  · **Журнал запросов называет CLI, модель и токены.** У каждого запроса видно, какой CLI и какая модель отвечали
  («Codex · gpt-5.6-luna · Разговор»), и сколько потратил каждый ход: из кэша, записано в кэш, новых, ответ.
- **Filters in the request log.** Requests are grouped by kind (talk, recognition, speech, notes, features and agents,
  service, screen loads), the noisy ones are hidden by default; chips show only problems or requests over 3 s, one
  CLI, or only this conversation. Speech of a reply folds under the turn it voiced. · **Фильтры в журнале
  запросов.** Запросы разложены по видам (разговор, распознавание, речь, заметки, фичи и агенты, служебные,
  загрузки экранов), шумные скрыты по умолчанию; чипы оставляют только проблемы или запросы дольше 3 с, один CLI или
  только этот разговор. Озвучка ответа сворачивается под ход, который она озвучила.
- **Home tiles line up.** The counters on the home screen are one strip: label, big number, unit. · **Плитки на
  главной выровнены.** Счётчики на главной — одна полоса: подпись, крупное число, единица.
