## New · Новое

- **Files in Claude sessions.** A paperclip in the reply box attaches photos, a camera shot, a picture from the
  clipboard or any file from the phone's Files — on the Mac, pick a file, paste it or drop it on the window. Claude
  sees pictures right away and opens other files itself; they're kept in Walkship's folder on the Mac, not in your
  project. A message can be just files. · **Файлы в сессиях Claude.** Скрепка в поле ответа прикладывает фото,
  снимок с камеры, картинку из буфера или любой файл из «Файлов» телефона, а на Mac — выбранный, вставленный или
  перетащенный в окно файл. Картинки Claude видит сразу, остальные файлы открывает сам; они лежат в папке Walkship
  на Mac, а не в твоём проекте. Сообщение может состоять из одних файлов.
- **Stop Claude, and see its goal.** While Claude works on a session started from Walkship, the send button turns
  into «Stop». A goal set with `/goal` shows above the reply box with how its checks went, and can be cleared. ·
  **Остановить Claude и видеть его цель.** Пока Claude работает в сессии, начатой из Walkship, кнопка отправки
  становится «Остановить». Цель, заданная через `/goal`, видна над полем ответа вместе с ходом проверок, и её можно
  снять.
- **Pick the model for a new session.** Fable, Opus, Sonnet or Haiku and the effort level — or keep what your last
  session in that folder used. The folder list shows the five latest, the rest are a search away; on wide screens
  the new session opens beside the list. · **Модель для новой сессии.** Fable, Opus, Sonnet или Haiku и уровень
  усилий — или то, что стояло в последней сессии в этой папке. В списке папок пять последних, остальные — через
  поиск; на широком экране новая сессия открывается рядом со списком.
- **The commit tree.** «History» on a project's Git page draws every branch as a graph, GitHub's branches and tags
  too. Switch to a branch, to one that's only on GitHub or to any commit, and start a new branch from any commit. ·
  **Дерево коммитов.** «История» на странице «Git» проекта рисует все ветки графом, вместе с ветками и тегами
  GitHub. Можно перейти на ветку, на ветку, которая есть только на GitHub, или на любой коммит, и начать новую
  ветку от любого коммита.
- **A softer dark theme.** The dark background and text are a touch lighter and easier on the eyes. · **Тёмная
  тема мягче.** Фон и текст в тёмной теме чуть светлее, глазам спокойнее.

The phone and the Mac talk the same protocol as 1.8.0–1.13.0, so they can be updated in any order; files in
Claude sessions need both on 1.14.0. · Телефон и Mac говорят на том же протоколе, что и 1.8.0–1.13.0, поэтому
обновлять их можно в любом порядке; файлам в сессиях Claude нужны обе стороны версии 1.14.0.
