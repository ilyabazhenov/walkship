**Claude or Codex — your choice for every role. And Walkship speaks English.** · **Claude или Codex — на выбор для
каждой роли. И Walkship говорит по-английски.**

Conversations, summaries and implementation can each run on Claude Code or on Codex (ChatGPT subscription), with a
model of their own. One setting — **Settings → Language** — switches the app, the assistant and the voice to English.
· Разговор, итоги и реализация — каждый может идти через Claude Code или через Codex (подписка ChatGPT), со своей
моделью. Одна настройка — **Настройки → Язык** — переключает приложение, ассистента и голос на английский.

## New · Новое

- **Codex on equal terms.** In **Agents and models** the conversation, summaries and implementation each pick Claude or
  Codex and a model — Codex models come from your ChatGPT account. The spoken conversation through Codex streams like
  Claude's, reads the project's code, uses Walkship's memory and searches the web; it can't write to the project or
  read files outside it, and your own Codex skills, hooks and MCP servers stay out of it. With only Codex on the Mac,
  everything runs through Codex. · **Codex наравне с Claude.** В «Агенты и модели» разговор, итоги и реализация
  выбирают Claude или Codex и модель — модели Codex берутся из твоего аккаунта ChatGPT. Разговор через Codex
  озвучивается по мере ответа, как у Claude, читает код проекта, память Walkship и интернет; писать в проект и читать
  файлы вне его он не может, а твои skills, хуки и MCP-серверы Codex в него не попадают. Если на Mac есть только
  Codex, всё идёт через него.
- **When a limit runs out, the other subscription takes over.** The assistant asks by voice — "The Claude limit is
  used up until 6:40 PM. Go on with Codex?" — and a "yes" moves the discussion over. Summaries and notes switch on
  their own. · **Кончился лимит — выручает другая подписка.** Ассистент спросит голосом: «Лимит Claude закончился до
  18:40. Продолжить на Codex?» — и «да» переводит обсуждение. Итоги и заметки переключаются сами.
- **Both subscriptions in one place.** **Subscriptions** shows the 5-hour and weekly windows of Claude and Codex and
  your ChatGPT plan; the badge warns about whichever is closer to its limit. · **Обе подписки в одном месте.**
  «Подписки» показывают пятичасовое и недельное окна Claude и Codex и план ChatGPT; бейдж предупреждает о той, что
  ближе к пределу.
- **Codex as the implementation agent, with a model.** Runs on the model you pick, read the project's CLAUDE.md when
  there's no AGENTS.md, and show which model did the work. · **Codex-агент с выбранной моделью.** Прогоны идут на
  выбранной модели, читают CLAUDE.md проекта, если нет AGENTS.md, и показывают, какой моделью сделаны.
- **First run needs Claude Code or Codex** — install and sign in to either from the setup screen. · **Для первого
  запуска нужен Claude Code или Codex** — установка и вход для обоих прямо с экрана настройки.
- **English everywhere.** The phone and the Mac app, menus, notifications, the first-run setup; the assistant
  converses, sums up, writes specs and retells agent runs in English, with four neural English voices. A new install
  takes the Mac's language; existing installs stay in Russian until you switch. · **Английский везде.** Телефон и
  приложение на Mac, меню, уведомления, первая настройка; ассистент разговаривает, подводит итоги, пишет спецификации
  и пересказывает работу агента по-английски, с четырьмя английскими нейро-голосами. Новая установка берёт язык macOS,
  существующие остаются на русском, пока не переключишь.
- **Projects move between Macs.** Project paths are stored relative to the projects folder. · **Проекты переезжают
  между Mac.** Пути проектов хранятся относительно папки проектов.
- Fixes: the limit reset time no longer reads "3 h 60 min"; times follow the language (8:53 PM / 20:53). ·
  Исправлено: время сброса лимита больше не бывает «3 ч 60 мин»; время следует языку.
