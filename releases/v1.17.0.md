## New · Новое

- **Claude sign-in check.** Every 30 minutes the Mac checks that Claude Code is still signed in. If it isn't, you get
  one push while you're away, a banner on the home screen and a red dot on the settings gear; Settings → «Claude
  sign-in» has «Sign in in Terminal». A reply that failed for this reason says so and offers to retry. Walkship keeps
  no Claude token of its own. · **Проверка входа в Claude.** Раз в 30 минут Mac проверяет, что Claude Code всё ещё
  залогинен. Если нет — один пуш, пока тебя нет рядом, плашка на главном экране и красная точка на шестерёнке
  настроек; в «Настройки → Вход Claude» есть «Войти в Терминале». Ответ, сорвавшийся из-за этого, так и говорит и
  предлагает повторить. Своего токена Claude Walkship не хранит.
- **Quieter pushes.** A push says that a reply or a run is ready, not what's in it. Settings → Notifications → «With
  the reply's start» brings the text back to the lock screen. · **Пуши скромнее.** Пуш говорит, что ответ или запуск
  готов, но не пересказывает его. «Настройки → Уведомления → С началом ответа» вернёт текст на заблокированный экран.
- **Settings say what's true.** «Away from home» on the Mac reads the real relay setting; a limit window that has
  reset counts from zero; «Connection» on the Mac shows whether the server answers. Plainer values on the right, and
  every section's title sits on the window buttons' line. · **Настройки говорят правду.** «Работа вне дома» на Mac
  показывает настоящую настройку ретранслятора; окно лимита, которое уже сбросилось, считается с нуля;
  «Подключение» на Mac показывает, отвечает ли сервер. Значения справа проще, а заголовок каждого раздела стоит на
  одной линии с кнопками окна.

## Security · Безопасность

A whole-app audit in October, and its fixes: · Аудит всего приложения в октябре и исправления по нему:

- The phone keeps the Mac's token in the system keychain, and Android no longer backs the app up. · Телефон хранит
  токен Mac в системной связке ключей, а Android больше не делает резервную копию приложения.
- An encrypted request's body is bound to its seal, so nobody on the way can swap it. · Тело зашифрованного запроса
  привязано к его печати, подменить его по дороге нельзя.
- The agent can't put a feature on «Now» by itself, a discussion reads only its own project, and git and Codex
  refuse secret files. · Агент не может сам поставить фичу в «Сейчас», обсуждение читает только свой проект, а git и
  Codex не отдают секретные файлы.
- A Claude session started from the phone gets none of Walkship's keys, and one whose folder is gone stops instead
  of running in your home folder. · Сессия Claude, запущенная с телефона, не получает ключей Walkship, а сессия, чья
  папка пропала, останавливается, а не работает в домашней папке.
- The phone opens only web links from replies and pages; a long command on a permission card shows its start and
  end. · Телефон открывает из ответов и страниц только веб-ссылки; длинная команда на карточке разрешения показывает
  начало и конец.

The phone and the Mac talk the same protocol as 1.8.0–1.16.0, so they can be updated in any order. · Телефон и Mac
говорят на том же протоколе, что и 1.8.0–1.16.0, поэтому обновлять их можно в любом порядке.
