## New · Новое

- **Claude Code sessions on the phone.** A new section lists the Claude Code sessions from the Claude app on your
  Mac: the ones waiting for your answer first, then the busy ones, then the rest by day, with the same unread dots
  as on the Mac. A session's transcript can be read in full, briefly or as answers only, with the screenshots,
  pictures, pages and artifacts it showed. Claude's questions and permission requests come to the phone while
  you're away from the Mac, with a push. You can start a new session in a project folder, or continue a Mac
  session in a copy. · **Сессии Claude Code на телефоне.** Новый раздел показывает сессии Claude Code из
  приложения Claude на Mac: сначала те, что ждут твоего ответа, потом работающие, потом остальные по дням — с теми
  же точками непрочитанного, что и на Mac. Переписку сессии можно читать полностью, кратко или только ответы,
  вместе со скриншотами, картинками, страницами и артефактами. Вопросы Claude и запросы разрешений приходят на
  телефон пушем, пока ты не за Mac. Можно начать новую сессию в папке проекта или продолжить сессию с Mac в копии.
- **Git from the phone.** A project's «Git» page shows the branch, what's new on GitHub and what's not pushed yet.
  Fetch, pull, commit (Walkship can suggest the message) and push — never with force; switch, create and delete
  branches, clean up merged ones and the agents' old copies, open any commit with its diff. Discarded changes can
  be brought back for a day. By voice: ask how the repository is doing, and commit with a short «yes». An agent
  now starts from the fresh version on GitHub, and asks where to start when your branch and GitHub diverged. ·
  **Git с телефона.** На странице «Git» проекта — ветка, что нового на GitHub и что ещё не отправлено. Обновить,
  забрать, закоммитить (Walkship предложит сообщение) и отправить — никогда с force; переключать, создавать и
  удалять ветки, убирать влитые и старые копии агентов, открыть любой коммит с его изменениями. Отменённые
  изменения можно вернуть в течение дня. Голосом: спросить, что с репозиторием, и закоммитить коротким «да». Агент
  теперь начинает от свежей версии с GitHub, а если твоя ветка и GitHub разошлись — спрашивает, откуда начать.
- **Read the project's code.** Files with syntax colors and uncommitted changes with their diffs, on the phone and
  the Mac; in a conversation the assistant can show you a file or the changes. · **Код проекта можно читать.**
  Файлы с подсветкой синтаксиса и незакоммиченные изменения с диффом — на телефоне и на Mac; в разговоре
  ассистент может показать файл или изменения.
- **Big screens.** iPads in landscape and an unfolded Fold get the Mac's sidebar (it can be hidden), and on wide
  screens a discussion or a feature opens beside its list. · **Большие экраны.** iPad в альбомной ориентации и
  раскрытый Fold получили боковую панель, как на Mac (её можно скрыть), а на широком экране обсуждение или фича
  открывается рядом со списком.
- **A more native Mac app.** Denser lists with hover actions, right-click menus and keyboard control (↑↓, Enter,
  Esc, ⌘N, ⌘⌫), sections on ⌘1–⌘4, the title bar merged into the window, project icons in the sidebar, and a talk
  button that shows — and lets you change — the project you're talking to. · **Mac-приложение стало роднее.**
  Плотнее списки с действиями при наведении, меню по правому клику и управление с клавиатуры (↑↓, Enter, Esc, ⌘N,
  ⌘⌫), разделы на ⌘1–⌘4, заголовок окна слился с окном, у проектов в боковой панели — значки, а кнопка разговора
  показывает проект, в который ты говоришь, и даёт его сменить.
- **The phone's best voice.** Without a Mac the phone now speaks with its best installed voice, or the one you
  pick in Settings → Voice, and tells you how to download a better one. · **Лучший голос телефона.** Без Mac
  телефон говорит лучшим из установленных голосов или тем, что выбран в Настройках → Голос, и подсказывает, как
  скачать голос получше.
- **Polish everywhere.** Errors offer «Retry», leaving unsaved edits asks first, settings are grouped more
  clearly, and phrases waiting to be sent can be deleted. · **Шлифовка повсюду.** У ошибок есть «Повторить»,
  уход с несохранённой правкой переспрашивает, настройки сгруппированы понятнее, а фразы, ждущие отправки, можно
  удалить.

The phone and the Mac talk the same protocol as 1.8.0–1.12.1, so they can be updated in any order; the new
sections need the Mac on 1.13.0. · Телефон и Mac говорят на том же протоколе, что и 1.8.0–1.12.1, поэтому
обновлять их можно в любом порядке; новым разделам нужен Mac версии 1.13.0.
