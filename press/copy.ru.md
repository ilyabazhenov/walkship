# Walkship — тексты для страницы (русский)

Готовые блоки для лендинга, стора, поста или письма. Порядок — как на странице `docs/ru/index.html`.

## Имя и слоган

- Имя: **Walkship** (по-русски — «Уокшип»). Одна заглавная буква: не WalkShip и не WALKSHIP.
- Слоган: **Ушёл гулять — вернулся к готовому PR.**
- Слоган на английском (можно и в русских текстах): *Go for a walk. Come back to a PR.*

## Описания

**Одна строка (до 80 знаков).**
Голосовой партнёр для твоих проектов: обсуждаешь на ходу, код пишет агент на Mac.

**Коротко (до 200 знаков).**
Walkship — голосовой партнёр для разработчика. Обсуждаешь фичу на прогулке, он собирает спецификацию,
а Claude Code или Codex реализует её на твоём Mac и открывает пул-реквест.

**Абзац.**
Лучшие идеи приходят не за столом. Walkship — голосовой собеседник, который знает твои проекты: читает код и
историю git, помнит прошлые обсуждения и заметки. Говоришь с ним на ходу — он превращает разговор в решения,
открытые вопросы и фичи с критериями готовности. Одно нажатие — и Claude Code или Codex реализует фичу в отдельной
ветке на твоём Mac, прогоняет проверки и присылает пуш. Обсуждаешь результат голосом, говоришь «открывай» — и
пул-реквест готов. Всё работает на твоём Mac, по твоей подписке Claude, без облака Walkship.

## Первый экран

- Надзаголовок: `ГОЛОСОВОЙ ПАРТНЁР ДЛЯ ТВОИХ ПРОЕКТОВ`
- Заголовок: **Ушёл гулять — вернулся к готовому PR.**
- Подзаголовок: Обсуждаешь фичу голосом на прогулке. Walkship собирает из разговора спецификацию, а твой агент —
  Claude Code или Codex — реализует её на твоём Mac.
- Кнопки: **Скачать для Mac** · **APK для Android**
- Подпись под кнопками: Бета · Mac с Apple Silicon, macOS 14+ · нужен Claude Code или Codex

## Как это работает — три шага

1. **Говоришь.** Hands-free: говоришь, после паузы фраза уходит ассистенту, ответ звучит сразу, потом он снова
   слушает. Ассистент знает проект: читает код, историю git и заметки, помнит прошлые обсуждения.
2. **Он собирает итоги.** Скажи «оформляй» — разговор превращается в решения, открытые вопросы и фичи со
   спецификацией и критериями готовности.
3. **Агент пишет код.** Одно нажатие — Claude Code или Codex реализует фичу в отдельном git worktree, прогоняет
   проверки и коммитит. Пуш на телефон, пересказ результата голосом, «открывай» — и PR готов.

## Возможности

- **Быстрые заметки.** Мысль на ходу без разговора. Ассистент сам решает, к какому проекту она относится, а если
  не уверен — спросит.
- **Доска фич.** Все фичи всех проектов: черновики, очередь, агент в работе, готово. Запуск и перезапуск прямо с
  карточки.
- **Память.** «Что мы решали про настройки?» — ассистент найдёт ответ в прошлых обсуждениях любого проекта.
- **Сводка.** Одна кнопка — и голосом: что агенты закончили, где упали, какие PR ждут, какие вопросы открыты.
- **Макеты.** «Покажи, как будет выглядеть экран» — набросок прямо в разговоре и в спецификации фичи.
- **Продолжить на Mac.** Спецификация или расшифровка открывается в Claude Code, Cursor или Codex одним нажатием.
- **MCP для твоих агентов.** Claude Code, Cursor и Codex в репозитории видят идеи, решения и фичи проекта.
- **Внешние MCP-серверы.** Подключи Jira, Sentry или базу данных — ассистент будет пользоваться ими в разговоре.
- **Без связи ничего не теряется.** Сказанная фраза ждёт на телефоне и уходит сама, когда сервер снова доступен.

## Всё на твоём Mac

- Код уходит только агентам, которыми ты и так пользуешься, — Claude Code или Codex — через их
  локальные CLI под твоим логином. Ключи API не нужны.
- Никаких аккаунтов и облака Walkship. Сервер, база и голоса работают на Mac.
- Распознавание речи — Whisper на Mac и системное на телефоне. Голос ассистента — нейро-голоса, тоже локально.
- Телефон подключается к Mac по домашней сети или через Tailscale — по QR-коду, с одним токеном.
- Основная ветка не трогается: агент работает в отдельном worktree, а PR открываешь ты.

## Что нужно

- Mac с Apple Silicon (M1 и новее), macOS 14 Sonoma или новее.
- Claude Code с подпиской Claude (Pro или Max) или Codex с подпиской ChatGPT (Plus или Pro) — хватит одного, вместе
  тоже работают.
- ~5 ГБ свободного места: голосовой пакет (Whisper и нейро-голоса) занимает около 3,3 ГБ.
- git; для пул-реквестов — `gh` (GitHub CLI).
- По желанию — iPhone или телефон на Android и Tailscale, чтобы говорить вне дома.
- Интерфейс и голос: русский или английский — одна настройка на всё.

## Вопросы и ответы

**Это бесплатно?**
[Решить до публикации: бета бесплатная? будет ли платная версия?]

**Нужен ключ API?**
Нет. Всё идёт через Claude Code или Codex по твоей подписке Claude или ChatGPT.

**Можно вместо Claude Code использовать Codex?**
Да, для всего: в «Настройки → Агенты и модели» у разговора, итогов и реализации свой выбор — Claude или Codex и
модель. Если у одной подписки кончится лимит, ассистент предложит продолжить на другой.

**Куда уходит мой код?**
Только агентам, которыми ты пользуешься, — Claude Code или Codex — так же, как если бы ты запускал их сам. У Walkship нет своего сервера в облаке.

**Есть версия для iPhone?**
Да, она скоро появится в App Store. Android уже есть — APK на странице загрузки, а на Mac можно говорить прямо в приложении.

**Агент не сломает мой репозиторий?**
Он работает в отдельном git worktree на своей ветке. Основная ветка остаётся как была, а PR открывается только по
твоей команде.

**На каких языках?**
На русском и английском. Одна настройка переключает экраны, ассистента и голос — и на Mac, и на телефоне.

**Как обновляться?**
Приложение само проверяет новые версии и предлагает скачать их из строки меню. Данные остаются на месте.

## Легенда (для «О проекте», поста, пресс-релиза)

**Walkship** = *walk* + *ship*. Лучшие идеи приходят на прогулке, а *ship* на языке разработчиков значит «выпустить».
Второй слой: суффикс *-ship*, как в *partnership* — прогулочное партнёрство, тот, с кем думаешь вслух.

Аристотель обсуждал идеи, прохаживаясь по галерее Ликея. Дарвин думал, нарезая круги по своей тропе Sandwalk.
Ницше доверял только мыслям, пришедшим на ходу. Раньше такие прогулки заканчивались забытыми мыслями. Прогулка с
Walkship заканчивается пул-реквестом.

Знак: фисташковый диск «готово» с галочкой, вокруг — записанная фраза, столбики голоса с неровными слогами и паузами.
Голос вокруг, результат в центре: сказал — сделано.
