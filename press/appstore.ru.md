## Описание (4000)

```
Walkship — голосовой партнёр для твоих проектов. Обсуждаешь фичу или новую идею на прогулке — ассистент знает код, историю git и ваши прошлые разговоры. Он собирает из разговора спецификацию, а твой агент реализует её на Mac. Возвращаешься — а тебя ждёт пул-реквест.

КАК ЭТО РАБОТАЕТ
• Говоришь. Без рук: говоришь, после паузы ассистент отвечает голосом и снова слушает. Перебить можно нажатием в любой момент, а можно писать текстом.
• Он собирает итоги. Скажи «оформляй» — разговор превращается в решения, открытые вопросы и фичи со спецификацией и критериями готовности.
• Агент пишет код. Одно нажатие — Claude Code или Codex реализует фичу в отдельной ветке на Mac и прогоняет проверки. Приходит уведомление, пересказ голосом, а пул-реквест открывается по твоей команде.

ВСЁ, ЧТО НУЖНО ПРОГУЛКЕ С МЫСЛЯМИ
• Быстрые заметки — мысль на ходу без разговора; ассистент сам отнесёт её к нужному проекту, а если не уверен — спросит.
• Доска фич — все фичи всех проектов: черновики, очередь, агент в работе, готово.
• Память — «Что мы решали про настройки?» Ассистент найдёт ответ в прошлых обсуждениях любого проекта.
• Сводка — одна кнопка, и голосом: что агенты закончили, где упали, что ещё открыто.
• Макеты — «Покажи, как будет выглядеть экран» — прямо в разговоре.
• Идеи до кода — проект можно начать без репозитория и подключить код, когда он появится; тогда задачи уйдут агенту. Есть и пресеты для поездки, ремонта, переезда и события.
• Когда Mac недоступен — сказанная фраза ждёт на телефоне, а можно продолжить разговор через модель по своему API-ключу; когда Mac вернётся, всё переедет на него.
• Русский и английский — одна настройка для экранов, ассистента и голоса.

ЧТО НУЖНО
Walkship на iPhone работает вместе с бесплатным приложением Walkship для Mac, которое делает всю работу:
• Mac с Apple Silicon и macOS 14 или новее, на нём Walkship для Mac с сайта ilyabazhenov.github.io/walkship/ru
• Claude Code с подпиской Claude или Codex с подпиской ChatGPT — хватит одного
• Телефон подключается к Mac по QR-коду — через домашнюю сеть или Tailscale вне дома
• По желанию — свой API-ключ DeepSeek или другой модели в стиле OpenAI, чтобы говорить, пока Mac недоступен

ПРИВАТНОСТЬ
Никаких аккаунтов, серверов Walkship, аналитики и рекламы. Разговоры и проекты остаются на твоём Mac, код уходит только агенту, которым ты уже пользуешься, под твоим логином. Без Mac телефон хранит их сам и говорит напрямую с моделью, которую ты настроил со своим ключом. Основная ветка не трогается: агент работает в отдельном git worktree, а пул-реквест открывается только по твоей команде.
```
