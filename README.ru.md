Лучшие идеи редко приходят за столом. Walkship знает твой код, историю git и прошлые обсуждения. Говоришь с ним на
ходу — и разговор превращается в решения, открытые вопросы и фичи с критериями готовности. Одно нажатие — и твой
агент реализует фичу в отдельной ветке на твоём Mac, прогоняет проверки и присылает пуш на телефон. Обсуждаешь
результат голосом, говоришь «открывай» — и пул-реквест готов.

> [!NOTE]
> **Бета.** Walkship говорит по-русски и по-английски — одна настройка для экранов, ассистента и голоса.

## Что ещё умеет

- **Быстрые заметки.** Мысль без разговора — ассистент сам найдёт ей проект.
- **Доска фич.** Все фичи всех проектов: черновики, очередь, агент за работой, готово.
- **Память.** «Что мы решили про настройки?» — найдётся в прошлых обсуждениях любого проекта.
- **Сводка.** Одна кнопка — и слышишь, что агенты закончили, где упали и какие PR ждут.
- **Макеты.** «Покажи, как будет выглядеть экран» — набросок прямо в разговоре.
- **Продолжить на Mac.** Спецификацию или расшифровку можно открыть в Claude Code, Cursor или Codex одним нажатием.
- **MCP в обе стороны.** Твои агенты видят идеи и фичи проекта; твои MCP-серверы (Jira, Sentry, база) доступны
  в разговоре.

**До кода.** Проект можно начать без репозитория: идея продукта, которую обсуждаешь за несколько прогулок, — с
памятью и итогами, где вместо фич список задач. Когда появится репозиторий, «Подключить код» привяжет его, и задачи
можно будет отдать агенту. Есть и пресеты для поездки, ремонта, переезда и события.

**Когда Mac недоступен.** Телефон может продолжить разговор через модель по твоему API-ключу (DeepSeek или любой API
в стиле OpenAI) и помнит, что Mac знал о проекте; когда Mac вернётся, всё переедет на него.

## Всё на твоём Mac

| Что | Где работает |
|---|---|
| **Сервер, база, речь, голоса** | На Mac: распознавание Whisper и нейро-голоса, данные в `~/.voice-assistant` |
| **Разговор, итоги, код** | Локальный Claude Code или Codex — для каждого свой выбор — под твоим логином и по твоей подписке, без ключей API |
| **Телефон ↔ Mac** | Подключение по QR-коду; дома напрямую, вне дома через ретранслятор со сквозным шифрованием |
| **Аккаунты** | Не нужны, облака Walkship нет — см. [политику конфиденциальности](https://walkship.app/ru/privacy/) |

## Установка

**Что нужно:** Mac с Apple Silicon и macOS 14 или новее · [Claude Code](https://claude.com/claude-code) с подпиской
Claude или Codex с подпиской ChatGPT — хватит одного · около 5 ГБ свободного места · git, для пул-реквестов — `gh`.

1. Скачай `Walkship-<версия>-arm64.dmg` из [последнего релиза](https://github.com/ilyabazhenov/walkship/releases/latest)
   и перетащи Walkship в «Программы». Он подписан и нотаризован.
2. Открой его. Экран настройки проведёт через вход в Claude Code, выбор папки с проектами и установку голосового
   пакета (~3,3 ГБ).
3. По желанию, Android: установи `Walkship-<версия>.apk` из того же релиза и отсканируй QR-код с экрана настройки на
   Mac. Android попросит разрешить установку приложений из браузера.

## Проблемы и отзывы

[Создай issue](https://github.com/ilyabazhenov/walkship/issues/new/choose). В приложении на Mac **Справка → Сообщить
о проблеме** сохраняет на Рабочий стол zip с версиями, состоянием и журналом сервера; тексты разговоров попадают
туда, только если поставить галочку. Посмотри его, прежде чем прикладывать. Об уязвимостях — приватно, см.
[SECURITY.md](SECURITY.md).
